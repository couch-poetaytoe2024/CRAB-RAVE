# CRAB-RAVE

A personal project combining my love for crabs and robotics. Ever wanted a crab that can walk, wave its claws, show emotions, and rave to Taylor Swift?

## Project structure

```text
CRAB-RAVE/
├── arduino/   # Arduino movement and servo code
├── python/    # Computer controls and music detection
├── cad/       # 3D-printable body, leg, and claw designs
├── docs/      # Wiring, servo map, and build notes
└── media/     # Project photos and videos
```

## Current plan

- Build a four-legged crab using 12 micro servos.
- Control it manually from a computer.
- Add LED-screen facial expressions.
- Make it detect music and dance to the beat.

## Start here

1. Record every servo in [docs/servo_map.md](docs/servo_map.md).
2. Document the wiring in [docs/wiring.md](docs/wiring.md).
3. Test individual servos with [arduino/servo_test.ino](arduino/servo_test.ino).
4. Track each build session in [docs/build_log.md](docs/build_log.md).
